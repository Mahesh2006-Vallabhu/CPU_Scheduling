Operating Systems Scheduling Theory

Definitions, principles, trade-offs, and preemption comparisons

Definition: Allocates CPU to processes in strict chronological order of arrival in ready queue (FIFO).

Advantages:
  • Simple to implement via FIFO queue.
  • No starvation; every process runs.
Disadvantages:
  • Convoy Effect: Short processes stuck behind long ones.
  • Suboptimal average waiting time.

Definition: Selects process with smallest CPU burst time among arrived candidates.

Advantages:
  • Provably optimal average waiting time for non-preemptive algorithms.
Disadvantages:
  • Future CPU bursts hard to predict.
  • Potential starvation for long burst jobs.

Definition: Preemptive SJF. If a newly arrived process has less remaining time than current executing job, CPU is preempted.

Advantages:
  • Lowest overall average waiting time among all scheduling algorithms.
Disadvantages:
  • Higher context switching overhead.

Definition: CPU allocated to process with highest priority (lower integer = higher priority in this simulator).

Advantages:
  • Guarantees mission-critical OS tasks run first.
Disadvantages:
  • Starvation of low-priority jobs (solved via Aging).

Definition: Allocates a fixed time slice (Quantum q) cyclically across all ready processes.

Advantages:
  • Fair CPU allocation with zero starvation.
  • Ideal for interactive time-sharing systems.
Disadvantages:
  • High context switching if quantum q is too small.

OS Scheduling Formulas Reference

Standard formulas used in operating system theory and academic examinations

Turnaround Time (TAT)
TAT = Completion Time (CT) − Arrival Time (AT)
Total duration elapsed from process arrival to final completion.
Waiting Time (WT)
WT = Turnaround Time (TAT) − Burst Time (BT)
Cumulative time spent in ready queue waiting for CPU allocation.
Response Time (RT)
RT = First Start Time − Arrival Time (AT)
Duration from arrival until CPU is first granted to the process.
CPU Utilization (%)
CPU Util = (Busy Time / Total Time) × 100%
Percentage of execution time during which CPU was non-idle.
Throughput
Throughput = Completed Processes / Total Time
Number of completed processes delivered per unit of simulation time.
Context Switches
Count of (Process Preemptions: Pᵢ ➔ Pⱼ)
Tracks overhead transitions between distinct scheduled processes.
